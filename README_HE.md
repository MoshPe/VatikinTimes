# Vatikin Times - מדריך בעברית

Vatikin Times היא תוכנת Windows קטנה ליצירת לוח זמני תפילה שבועי בפורמט Excel עבור בית הכנסת משמרת -- ותיקין. התוכנה מושכת נתונים ממקורות חיצוניים, מחשבת את זמני ותיקין, ומייצרת קובץ `.xlsx` מוכן להדפסה בעברית ובכיוון ימין לשמאל.

## יכולות עיקריות

- בחירת עיר: קריות, חיפה, ירושלים, תל אביב, באר שבע.
- רשימת פרשות לפי לוח ארץ ישראל.
- יצירת לוח שבועי לפי פרשת השבוע שנבחרה.
- זמני היום:
  - עלות השחר
  - זמן טלית ותפילין
  - הנץ החמה (הנראה)
  - שחרית ותיקין
- שימוש ב-Chai Tables עבור הנץ הנראה, עם גיבוי מנתוני Hebcal.
- התאמת שחרית ותיקין לשבת ויום טוב.
- שורת דף יומי.
- שורת ימים מיוחדים הכוללת:
  - חגים
  - ראש חודש
  - מולד
  - כניסת החג בערב יום טוב לפי העיר שנבחרה
- הוספת הפטרה בעברית, כולל מראה מקום ופתיחת ההפטרה כאשר ניתן.
- עיצוב גיליון Excel להדפסה בעמוד אחד, לרוחב, ב-A4.
- אפשרות להוסיף הערות חופשיות שיופיעו בתחתית הלוח.

## מקורות מידע

התוכנה משתמשת במקורות הבאים בזמן יצירת הלוח:

- Hebcal Calendar API עבור פרשות, תאריכים עבריים, דף יומי, חגים, ראש חודש, מולד וכניסת החג.
- Hebcal Zmanim API עבור זמני היום.
- Hebcal Leyning API עבור הפטרה.
- Sefaria API עבור פתיחת ההפטרה בעברית.
- Chai Tables עבור זמן הנץ הנראה, כאשר הנתונים זמינים.

נדרש חיבור אינטרנט בזמן יצירת הלוח.

## דרישות מערכת

- Python 3.11 ומעלה מומלץ.
- Windows הוא יעד השימוש המרכזי.
- Excel או תוכנה אחרת שיכולה לפתוח קבצי `.xlsx`.

התקנת ספריות:

```powershell
python -m pip install -r requirements.txt
```

אם פקודת `python` משתמשת בסביבה שאין בה PyQt6 או openpyxl, יש להריץ את התוכנה עם סביבת Python שבה הספריות מותקנות.

## הפעלה

```powershell
python main.py
```

לאחר פתיחת התוכנה:

1. בוחרים עיר.
2. בוחרים פרשת שבוע.
3. מוסיפים הערות אם צריך.
4. לוחצים על `עדכן והכן להדפסה`.

התוכנה יוצרת קובץ Excel בתיקיית הפרויקט ומנסה לפתוח אותו אוטומטית.

## בניית קובץ הרצה

בקובץ `install` קיימת פקודת PyInstaller:

```powershell
pyinstaller --onefile --noconsole --hidden-import openpyxl.cell._writer main.py
```

קבצי Excel שנוצרים אינם נשמרים ב-git.

## הערות על קובץ ה-Excel

הגיליון מוגדר כך:

- כיוון ימין לשמאל.
- A4 לרוחב.
- אזור הדפסה מוגבל לעמודות הלוח.
- התאמה להדפסה בעמוד אחד.
- שימוש בגופן David בכותרת, בתאריכים ובכותרות הימים במקומות המתאימים.
- שורות ארוכות נעטפות, למשל מולד וכניסת החג.

אם Excel עדיין מציג חיתוך בתצוגת עריכה רגילה, מומלץ לבדוק את תצוגת ההדפסה. הייצוא מותאם בעיקר להדפסה של אזור הלוח בעמוד אחד.

## בדיקות

הרצת בדיקות:

```powershell
python -m unittest test_main.py
```

הבדיקות מכסות בין השאר:

- שיוך אירועים לימים הנכונים בשבוע.
- הפרדת השנה העברית משורת התאריכים.
- זיהוי יום טוב.
- שימוש בעיר שנבחרה עבור כניסת החג.
- שימוש בלוח ארץ ישראל עבור פרשות.
- עיצוב הפטרה ופתיחת הפטרה.
- הגדרות עיצוב והדפסה של קובץ Excel.

## מבנה הפרויקט

- `main.py` - קוד התוכנה, ממשק PyQt6, משיכת נתונים וייצוא Excel.
- `test_main.py` - בדיקות יחידה.
- `requirements.txt` - ספריות Python נדרשות.
- `install` - פקודת בנייה עם PyInstaller.
- `main_backup.py` - עותק גיבוי ישן שנשאר במאגר.

## פתרון תקלות

אם הפרשות אינן נכונות, יש לוודא שהבקשות ל-Hebcal משתמשות בלוח ארץ ישראל (`i=on`). התוכנה עושה זאת גם ברשימת הפרשות וגם בנתוני השבוע.

אם כניסת החג חסרה, יש לוודא שבשבוע שנבחר יש ערב יום טוב וש-Hebcal מחזיר זמני הדלקת נרות עבור העיר שנבחרה.

אם התוכנה לא נפתחת, יש לוודא ש-PyQt6 מותקן בסביבת ה-Python שבה מריצים את `main.py`.

אם הבדיקות נכשלות בגלל PyQt6, קובץ הבדיקות כולל תחליף קל למחלקות GUI, אך עדיין נדרשת התקנה של `openpyxl`.
